---

# 3. Definition of Ready (DoR)

Uma funcionalidade estará pronta para desenvolvimento quando:

1. O requisito estiver claramente definido.
2. Os critérios de aceitação estiverem documentados.
3. As dependências necessárias estiverem identificadas.
4. A equipe compreender o objetivo da funcionalidade.
5. A tarefa estiver priorizada no planejamento.

---

# 4. Definition of Done (DoD)

Uma funcionalidade será considerada concluída quando:

1. Todos os requisitos forem implementados.
2. Os testes forem executados com sucesso.
3. Não existirem erros críticos conhecidos.
4. O código estiver versionado no GitHub.
5. A documentação da atividade estiver atualizada.
