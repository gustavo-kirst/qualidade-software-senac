## 🎯 Objetivo do Repositório

Este repositório reúne as atividades desenvolvidas na disciplina de **Qualidade de Software** do Centro Universitário Senac-RS, utilizando a metodologia **PBL (Problem-Based Learning)**.

Além da documentação das atividades, o projeto contém implementações práticas de testes automatizados em Python, demonstrando a aplicação dos conceitos estudados ao longo da disciplina.

## ▶️ Como executar os testes

Instale as dependências:

```bash
pip install pytest
pip install pytest-playwright
pip install pytest-bdd
playwright install
```

Execute todos os testes:

```bash
python -m pytest -v
```

Resultado atual:

```text
============================= test session starts =============================

6 passed

==========================================================================
```
